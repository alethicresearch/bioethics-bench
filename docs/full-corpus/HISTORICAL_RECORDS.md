# Working records under `docs/full-corpus/`

The audit ledgers, checkpoints, batch files and review records in this directory are dated
evidence of how the cases were built and checked. They are kept as written.

They use the working vocabulary of the time — *case family* for a case, *candidate* or
*candidate universe* for a policy and the set of policies, *projection* for the policies selected
for one evaluation, *geometry* for how many policies of each type a case carries. Read them with
that mapping in mind rather than rewriting them: changing an audit record changes the evidence.

New writing uses the plain terms in `AGENTS.md`: case, policy, policy type (Public, Expert,
Framework), sourcing (Direct source, Inferred from source, Constructed), and evaluation setup.
