## M036 — Withholding versus withdrawing the same treatment
**Scenario:** PASS only if prognosis, goals, burdens, and intervention are genuinely held constant.  
**Universe (6):** treat withholding and withdrawing as ethically equivalent when the intervention no longer serves patient goals (✓ direct professional); require a higher procedural threshold for withdrawal because stopping an established treatment creates reliance/causal/moral concerns (✓ source-informed public intuition + normative scholarship); use explicit time-limited trials so initiation does not create a presumption of indefinite continuation (✓ professional/procedural); when uncertainty is high, start treatment with stopping criteria rather than withhold because reversibility preserves options (constructed comparator); avoid starting when likely later withdrawal would be psychologically/institutionally harder and expected benefit is low (constructed comparator); formal-equivalence framework versus morally relevant act/omission/reliance framework (✓ frameworks, represented as actionable rules rather than abstract claims).  
**Source-grounded:** likely asymmetric and unusually informative. **Expanded:** YES. **Demo:** VERY HIGH. **Action:** EXPAND-UNIVERSE.
