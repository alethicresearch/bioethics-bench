## Interpretation of the `2×1×2` pattern

The repeated single-expert structure appears to reflect a real feature of the source ecology: professional organizations often synthesize contested considerations into one practical guidance architecture even when affected publics and normative frameworks remain plural. Examples include patient-centered diagnosis disclosure, adolescent confidentiality, telemedicine escalation, cochlear-implant counseling, brain-death accommodation, clinically assisted nutrition/hydration, prenatal screening and posthumous reproduction.

The corpus should **not** respond by manufacturing a second expert recommendation. The Mean-pinned asymmetric profile exists precisely so source-class consensus can remain visible.

This observation should eventually be reported as a descriptive corpus property, not as evidence that experts are more morally correct, more coherent, or less diverse in general. The profile count will be reassessed at n=100 and n=200.

## Non-executable cases are part of the resource, not failures

The first 50 already demonstrate several distinct reasons a case may remain non-executable:

1. **Evidence-granularity gap:** relevant public attitudes exist but do not directly support the institutional policy being represented (for example M009 CPR process, M046 hospital abortion-service scope).
2. **Preference-versus-policy collapse:** people differ personally, but honest institutional translation yields one shared policy (for example M022 periviable resuscitation, M043 multifetal pregnancy reduction).
3. **Moving policy object:** the technology/evidence/jurisdiction is changing too quickly for a stable executable set (for example M024 adolescent gender-affirming care, M032 psychiatric assisted dying, M044 uterus transplantation).
4. **Strong professional convergence:** the philosophical dispute is real but a second professional candidate would be invented (for example M014 pregnancy refusal, M016 parental refusal of curative cancer therapy).
5. **Legal sensitivity:** the ethical case is useful, but real-world law can dominate if the benchmark is not carefully stipulated (for example M038 somatic support after BD/DNC in pregnancy, M048 embryo disposition after separation).

Research completeness and executable eligibility therefore remain intentionally separate.

## Provenance rule clarified at this checkpoint

When a source supports the core policy but Bench authors add a narrow operational clause needed to make the candidate executable, **do not create a new schema concept**. Record the addition in the existing candidate `provenance.summary` using explicit wording such as:

`Bench-authored policy completion: [short description of the added operational clause].`

The `construction_method` continues to describe the primary derivation (`adapted-from-source`, `derived-from-framework`, etc.). This keeps authored completion visible in the record without expanding the provenance ontology.

## M005 correction decision

Independent review correctly identified that the current M005 `fw1` and `exp1` are action-near-identical. M005 should not be demoted automatically because a distinct principlist rule can be defended from veracity/autonomy:

**Revised fw1 direction:** when a capacitated patient has not expressed a wish to delegate or defer serious information, disclose the diagnosis truthfully rather than withholding it at the family's request, while allowing the patient to control depth, pacing and family involvement.

This is action-distinct from `exp1`, which first elicits information/family preferences and then follows the patient's chosen communication structure, and from `fw2`, which affirmatively supports patient-chosen family mediation/gradual disclosure. The partner/implementation custodian should make this narrow candidate/provenance correction and regenerate both M005 hashes atomically before treating the pair as clean.
