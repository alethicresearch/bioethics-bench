Policy sources

See where each policy comes from

The source label travels with each policy. On the Cases page, you can select any of these types and see the cases that contain them.

Direct source

The source itself supports substantially the same policy.

Inferred from source

The source supplies the underlying view or evidence, and the policy is a careful inference from it.

Ethical framework

The policy follows from an identified ethical principle or framework.

Constructed comparison

A serious policy option added for comparison and clearly identified as constructed.
